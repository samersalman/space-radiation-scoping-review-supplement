# Supplementary Materials: Database Search Strategies

Supplementary material for the scoping review **"Human Cancer Risk from Space Radiation Beyond Low Earth Orbit: Mechanisms, Evidence, and Countermeasures for Deep Space Exploration"** (submitted to the *Journal of Applied Physiology*).

This deposit contains the full, reproducible search strategies for the PRISMA-ScR–guided review: Ovid MEDLINE, Embase, Cochrane Central Register of Controlled Trials, Scopus, and Web of Science, each searched from inception through September 21, 2026. Each strategy lists the platform, search date, and line-by-line query syntax.

## Files
- `Supplementary_Search_Strategy.pdf` – search strategies (PDF)
- `Supplementary_Search_Strategy.docx` – editable version
